# Security Policy

## Supported Versions

Security updates and patches are applied to the latest release of `cli-ner`.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability or Safety Issue

If you discover a safety violation (such as an unblocked sensitive directory or an unsafe file deletion pattern) or a security vulnerability in `cli-ner`:

1. **Do not** open a public issue.
2. Please report the issue by opening a private GitHub Security Advisory on the repository:
   - Navigate to **Security** > **Advisories** > **Report a vulnerability** on [github.com/fabrizioriccardo73/cli-ner](https://github.com/fabrizioriccardo73/cli-ner)
3. Alternatively, contact the maintainer directly via email: `djfabrix@gmail.com`.

### What to Include
- Description of the safety violation or vulnerability.
- Steps to reproduce (including paths and command options used).
- Suggested fix or mitigation if known.

We take safety and user data protection extremely seriously and will investigate and patch verified issues promptly.
